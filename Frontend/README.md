# GreenMarket Frontend dengan Next.js

## Struktur File

- `/` - Landing Page (Halaman utama)
- `/login` - Halaman login pengguna
- `/register` - Halaman pendaftaran pengguna
- `/beranda-dashboard` - Dashboard setelah login
- `/profile` - Profil pengguna
- `/notifikasi` - Halaman notifikasi
- `/wishlist` - Daftar keinginan
- `/upload-produk` - Upload produk baru
- `/komunitas` - Halaman komunitas
- `/admin-panel` - Panel administrasi

## Cara Menjalankan Aplikasi

1. Pastikan Anda berada di direktori `greenmarket-frontend`
2. Jalankan perintah:
   ```
   npm run dev
   ```
3. Buka browser dan akses `http://localhost:3000`

## Fitur

- Integrasi penuh dengan Tailwind CSS
- Sistem autentikasi (login/registrasi)
- Responsive design
- Halaman admin panel
- Halaman komunitas
- Halaman dashboard pengguna

## Catatan

Semua file HTML dan CSS dari desain asli telah diintegrasikan ke dalam struktur Next.js dengan mempertahankan tampilan asli.
